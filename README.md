# 🎨 مغامرة الألوان – Color Adventure

نموذج أولي تفاعلي للعبة تعليمية عربية للأطفال من عمر 3 إلى 6 سنوات، صُمم لمساعدة الطفل على التعرّف إلى الألوان الأساسية من خلال الصور، اللمس، الصوت، الاختيارات والمكافآت.

## ما يتضمنه النموذج

- شاشة رئيسية عربية باتجاه RTL مع شخصية لولو المرشدة.
- شاشة اختيار خمسة مستويات تعليمية.
- المستوى الأول: اكتشاف الألوان مع النطق العربي عند الضغط.
- المستوى الثاني: اختيار اللون الصحيح من ثلاثة اختيارات.
- نظام نجوم وتشجيع لطيف عند الإجابة الصحيحة أو المحاولة الجديدة.
- شاشة جوائز وشارة عند جمع خمس نجوم.
- شاشة إعدادات مبسطة للصوت والموسيقى وتجربة آمنة.
- واجهة متجاوبة للشاشات الكبيرة والهواتف.
- لا توجد إعلانات أو روابط خارجية أو مشتريات داخل اللعبة.

## التشغيل محلياً

يتطلب المشروع Node.js وpnpm.

```bash
pnpm install
pnpm dev
```

لفحص الأنواع وبناء نسخة الإنتاج:

```bash
pnpm check
pnpm build
```

## التقنيات

React 19، TypeScript، Vite، Tailwind CSS، Web Speech API للنطق العربي، وWeb Audio API للمؤثرات الصوتية القصيرة.

## الأصول البصرية

تستخدم اللعبة أصولاً كرتونية أصلية مرفوعة إلى تخزين WebDev Storage، وتُحمّل أثناء تشغيل نسخة WebDev عبر مسارات `/manus-storage/...`. عند نقل المشروع إلى استضافة مستقلة، يجب استبدال هذه المسارات بأصول مستضافة ضمن بيئة الاستضافة الجديدة.

## الحالة الحالية

المستويان الأول والثاني قابلان للعب في النموذج الحالي. المستويات الثالث إلى الخامس تظهر كمسارات قادمة، وهي جاهزة للتوسعة بإضافة السحب والإفلات، الفرز، وتحدي الألوان.

## الأمان وتجربة الطفل

التصميم يعتمد على أزرار كبيرة، ألوان واضحة، رسائل غير عقابية، أنشطة قصيرة، وعدم عرض أي محتوى تجاري أو روابط خارجية.
